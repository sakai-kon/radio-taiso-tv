# Radio Taiso TV

祖母がiPhoneからラジオ体操を選び、YouTube公式アプリのCast機能でテレビ（REGZA 43Z570K）に映すためのシンプルなページです。

## 動作

- 「ラジオ体操 第一」ボタン → かんぽ生命公式YouTubeの第一の動画を開く
- 「ラジオ体操 第二」ボタン → かんぽ生命公式YouTubeの第二の動画を開く
- YouTubeアプリが開いたら、アプリ内のキャストアイコンからテレビを選ぶ

## 公開

GitHub Pagesを有効にしてください。

1. リポジトリの **Settings** を開く
2. 左メニューの **Pages** を開く
3. **Deploy from a branch** を選択
4. Branch を `main`、Folder を `/(root)` にして保存
5. 数分後、表示されたPages URLをiPhoneで開く

## 使用動画

かんぽ生命公式「ラジオ体操チャンネル」の動画です。

- 第一: https://www.youtube.com/watch?v=_YZZfaMGEOU
- 第二: https://www.youtube.com/watch?v=yi1TbzML2cU
- 公式チャンネル: https://www.youtube.com/@radiotaisou

## Castについて

このページは動画を選んでYouTubeのURLを開くランチャーです。iPhoneのWebページからCast接続先を直接選択・制御するものではありません。Castの操作はYouTube公式アプリ側で行います。

iPhoneとREGZAは同じWi-Fiネットワークに接続してください。YouTubeアプリがインストールされていない場合やUniversal Linkの設定によっては、動画がブラウザで開くことがあります。その場合はYouTubeアプリで開き直してください。
